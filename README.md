# JavaScript Todo List App

A console-based task management application built in **JavaScript**  to demonstrate core data structure operations using dynamic arrays.

---

## 🚀 Features
* **Dynamic Array Storage:** Utilizes JavaScript arrays and methods (`push()`, `splice()`) to add and remove tasks dynamically.
* **Interactive CLI Flow:** Uses Node.js `readline` module to handle asynchronous user input continuously.
* **Input Validation:** Protects against empty tasks and invalid menu selections.
